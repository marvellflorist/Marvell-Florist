Payment marks used on the shopping bag page.

- QRIS, BCA, GoPay: [Midtrans payment-logo collection](https://github.com/veritrans/logo). Midtrans [permits merchants to use this collection on their websites](https://docs.midtrans.com/docs/do-you-provide-logos-for-the-all-the-payment-types-on-midtrans).
- OVO: [OVO website logo](https://www.ovo.id/ovo_front_res/img/ovo-logo-white.png).

The PNGs were resized for web delivery without changing the artwork. The marks illustrate possible methods; iPaymu's hosted sandbox checkout determines which methods are active for a transaction.
